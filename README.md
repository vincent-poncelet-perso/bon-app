## Structure du dépôt

- `apps/` : applications exécutables (`web`, `mobile`, `api`)
- `packages/` : composants, logique métier et utilitaires partagés
- `tests/` : tests transverses et tests de bout en bout
- `product/` : vision, besoins, roadmap et backlog produit
- `architecture/` : architecture, flux, modèles et API
- `security/` : exigences, risques et contrôles de sécurité
- `operations/` : déploiement, supervision et procédures d’exploitation
- `marketing/` : positionnement et supports de commercialisation
- `decisions/` : décisions structurantes et ADR
- [Checklist de démarrage](product/getting-started-checklist.md) : documents à lire, étapes possibles et éléments restant à définir
